# Cloud6 Academy — Origin Version 🎓

**This single HTML file (~18,000 lines) was v1 of Cloud6 Academy** — a bilingual English/Spanish K-12 learning platform, built solo with Claude Code.

🔗 **The platform it became:** [nova-learns.vercel.app](https://nova-learns.vercel.app) — live and free to try

## The story

Cloud6 Academy started as one giant HTML file: lessons, quizzes, navigation, styling, everything. It worked. Students used it. Then it outgrew the file.

Today's production version (private repo) is a full **Next.js + Supabase** platform with:

- 📚 2,600+ bilingual EN/ES lessons — Math, Science, English, History, Financial Literacy, App Building (PK-12)
- 🧭 Placement quizzes
- 👨‍👩‍👧 Parent dashboards with bilingual progress summaries + weekly email digests
- 🏫 Teacher dashboards — classes, join codes, lesson assignment
- 🔥 Student streaks and badges
- 🤖 AI Tutor ("I don't get this" button) powered by the Anthropic API via Supabase Edge Functions
- ✅ FERPA / COPPA compliant

This repo stays public as a reminder of where it started — and proof that you should ship v1, even if it's one file.

**Stack (production):** Next.js • React • Supabase • Vercel • Anthropic API • Resend
